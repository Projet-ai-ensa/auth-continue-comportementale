# Collecteur navigateur

Responsable principal : Hiba. Coordination du contrat API : Imrane.

Ce dossier contient le JavaScript qui collecte les événements autorisés et calcule des caractéristiques agrégées.

Événements envisagés :
- mouvements de souris ;
- clics ;
- défilement ;
- intervalles temporels de clavier, si approuvés.

Ne jamais enregistrer les caractères saisis, le texte des champs ou les mots de passe.

Le format des données doit suivre `docs/API_CONTRACT.md`.
