# Infrastructure et déploiement

Responsable de coordination : Yahya.

Ce dossier contiendra les fichiers Docker, les configurations de déploiement et les exemples de variables d'environnement.

Le déploiement Cloud est facultatif. Le MVP doit d'abord fonctionner en local.

Ne jamais ajouter de secrets dans le dépôt. Utiliser un fichier `.env.example` sans valeur sensible et documenter les variables requises.
