# Tests

Responsable de coordination : Yahya. Chaque membre teste son propre composant.

Types de tests :
- tests unitaires des fonctions de features ;
- tests du schéma API ;
- tests du pipeline ML ;
- tests d'intégration frontend/collecteur/API ;
- tests de bout en bout sur des sessions synthétiques.

Les tests doivent utiliser des données fictives ou des données de test autorisées. Ne pas utiliser de mots de passe ou de données personnelles.
