# API — FastAPI

Responsable principal : Imrane.

Ce dossier contient l'API du projet.

Responsabilités :
- valider les données du collecteur ;
- associer les données à une session pseudonyme ;
- calculer ou recevoir les caractéristiques serveur ;
- appeler le pipeline ML ;
- appliquer une politique de risque ;
- enregistrer les résultats utiles ;
- fournir les données au dashboard.

Lire `docs/API_CONTRACT.md` avant d'implémenter une route.
